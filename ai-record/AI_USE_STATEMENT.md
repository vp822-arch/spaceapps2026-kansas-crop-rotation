# AI Use Statement (data-analysis part, Varun Pisharody)

For the data-analysis part of our project, Varun Pisharody worked with Claude, an AI assistant made by Anthropic (Claude Fable 5.2 and Claude Opus 5.5), on Nov 14–15, 2026. Claude wrote essentially all of the analysis code in this repository (each script says so). It also designed the crop-rotation scoring method, calibrated it and ran an exploratory check of its weather scores against real USDA NASS county yields (this does not test economics or rotation outcomes), and built the weekly auto-refresh (GitHub Actions to Cloudflare R2). It wrote the handoff guides and the references list, and it researched which NASA datasets to use. The team made the decisions that set the direction: the project idea, the focus on Kansas, giving farmers ranked crop rotations, scoring on more than just water, and using NASA data at the center. Varun ran the data downloads, created and controls all accounts and keys (Claude was not given credentials to use; the logs record two exposures, an Earthdata token pasted into the chat once and a weak database password visible in a screenshot, neither of which Claude used or stored, and both of which Varun replaced), and reviewed the results. Every number comes from public data (NASA POWER, USDA NASS, the U.S. Drought Monitor and K-State publications) and none was made up by the AI. The results were re-checked with an independent re-implementation. A full, timestamped log of everything the AI did is in `ai-record/AI-activity-log-part1.md` and `ai-record/AI-activity-log-part2.md`.
